# Лия для Android

Первая нативная версия голосовой помощницы для слабовидящего пользователя.

## Уже работает

- крупный высококонтрастный интерфейс;
- распознавание русских голосовых команд;
- озвучивание ответа;
- чтение доступного текста активного окна;
- нажатие по видимому тексту;
- прокрутка вверх и вниз;
- системные действия «Назад» и «Домой»;
- плавающая кнопка «Л» поверх приложений после включения службы доступности.
- режим «Перевод разговора рядом» для грузинского, английского и итальянского;
- русский перевод в подключённый наушник;
- перевод ответа пользователя через динамик телефона или крупным текстом.

## Безопасность

Ключ OpenAI нельзя помещать в APK. Подключение к модели должно идти через отдельный серверный endpoint. До его подключения приложение выполняет команды локально.
